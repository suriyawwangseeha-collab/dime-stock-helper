# ผู้ช่วยเลือกหุ้นสำหรับมือใหม่ (Dime)

เว็บแอปคัดกรองหุ้น/ETF สหรัฐฯ ตามระดับความเสี่ยง พร้อมราคาล่าสุดและสถิติความผันผวน 3–6 เดือน

- `index.html` — หน้าเว็บทั้งหมด (มีข้อมูลสำรองฝังไว้ เผื่อ API ใช้ไม่ได้)
- `api/data.js` — Vercel Serverless Function ดึงราคาจาก Yahoo Finance แคช 1 นาที
- เพิ่ม/ลดรายชื่อหุ้น: แก้ `SYMBOLS` ใน `api/data.js` และรายการ `U` ใน `index.html`

ใช้เพื่อการเรียนรู้ ไม่ใช่คำแนะนำการลงทุน
